🚨 FUNDAMENTAL FLAW — You spotted it: query has ZERO lexical overlap with answer
Query: “What should I serve for dinner this weekend with my homegrown ingredients?” — contains dinner, weekend, homegrown, ingredients
Answer chunk: “I've even harvested some cherry tomatoes from my garden.” — contains cherry, tomatoes, garden, basil, mint
Overlap = 0 words. FTS OR on 12 toks can NEVER rank it top 15 — it’s a semantic gap, not a BM25 tuning gap. This is why Hit 0 for 11/14.
Why RAG + HCIL + OKF didn't help: memories_fts porter + session_summaries_fts + atomic_claims_fts are ALL lexical FTS. OKF `like X,Y` needs “like” in query — dinner query has no “like”. HCIL session summary `[5:25 pm] creating a web app…` also has no cherry. No vector, no semantic.
Fix foremost: hybrid dense vectors (sqlite-vec embgemma2 768d) + late-interaction re-rank, so “homegrown ingredients” ↔ “cherry tomatoes from my garden” are close in vector space, then re-rank BM25 0.3. That's H2.1 hybrid, not more FTS.

The 11/14 failures are not “model is dumb” — they are Hit 0 (the piece was never inserted) vs Hit 1 but wrong (it was inserted, reasoning failed).
